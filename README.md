WeatherMap 

Project Description

WeatherMap is a web application that allows users to search for locations and view current weather information on an interactive map.

Features

* Search for locations by city name.
* Display current weather information.
* Interactive map using Leaflet and OpenStreetMap.
* Save favorite locations using LocalStorage.
* Display a five-day weather forecast.
* Responsive design for desktop and mobile devices.
* Loading indicators and error messages.

Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JavaScript)
* OpenWeatherMap API
* Nominatim Geocoding API
* Leaflet
* OpenStreetMap
* LocalStorage

How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open index.html in a web browser, or use the Live Server extension in Visual Studio Code.
4. Make sure the required API configuration is set correctly.
